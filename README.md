# 筆電價格預測分析

## 專案簡介

本專案使用 momo 購物平台的筆記型電腦商品資料，透過資料清洗、特徵工程與機器學習，建立筆電價格預測模型，並比較 Linear Regression、KNN 與 Decision Tree 三種演算法的預測表現。

專案特色是將螢幕解析度轉換為總像素數 `Total_px`，作為模型特徵之一，觀察硬體規格與筆電價格之間的關聯。

## 成果摘要

- 清洗後保留 **1,160 筆**有效資料，One-Hot 編碼後共 89 個特徵。
- 最佳模型為 **Linear Regression**：測試 R² = 0.8817、MAE = 4,565 元。
- 99.4% 的測試預測誤差落在 ±20,000 元內（以預測誤差絕對值計）。

## 模型比較

資料切分：Train 812 筆 / Test 348 筆（70:30）。

| 模型 | 參數 | 測試 R² | MAE（元） | MSE（元²） | 預測誤差 ±20,000 元比例 |
|---|---|---|---|---|---|
| Linear Regression | 預設 | 0.8817 | 4,565 | 36,587,781 | 99.4% |
| KNN | k=5 | 0.8531 | 4,690 | 45,413,284 | 98.0% |
| Decision Tree | max_depth=8 | 0.8012 | 5,172 | 61,469,204 | 96.8% |

指標說明：

- **R²**：模型對價格變異的解釋程度，越接近 1 越好。
- **MAE**：預測價格與實際價格的平均絕對誤差，單位為元。
- **MSE**：預測誤差平方的平均值，對較大的誤差更敏感。

Decision Tree 的訓練 R²（0.930）明顯高於測試 R²（0.801），有過擬合現象；Linear Regression 的訓練 R²（0.889）與測試 R²（0.882）差距不到 0.01。

## 資料處理與特徵工程

**資料清洗**

- SSD 容量去除單位並統一換算為 GB，排除 8 筆 eMMC 資料。
- 以 IQR 處理離群值，最終保留 1,160 筆。

**Total_px 特徵工程**

1. 原始解析度為文字格式，例如 `1920x1080`。
2. 用 Pandas `str.split` 拆出螢幕寬度（Width）與高度（Height）。
3. 計算 `Total_px = Width × Height`，代表螢幕總像素數。
4. 將解析度轉為單一數值特徵，納入模型訓練。

**其他處理**：類別欄位 One-Hot 編碼，數值欄位以 StandardScaler 標準化。

## 模型訓練與評估

- 比較 Linear Regression、KNN（k=5）、Decision Tree（max_depth=8）。
- 以 R²、MAE、MSE 評估，並檢視 Actual vs Predicted 散佈圖。
- 殘差分析：檢視殘差分布與 ±20K 內比例，並檢查誤差是否隨價格擴大。依 LR 預測價將測試集分三組，高價組的絕對誤差較大（3,583 → 5,758 元），相對誤差較低（15.3% → 10.0%）。

## 限制與注意事項

- 資料只來自 momo 單一平台、單一時間點，價格會隨時間與促銷變動，結果不代表其他平台或其他時期。
- 只做一次 70:30 切分，沒有做交叉驗證，R² 與 MAE 會受切分方式影響。
- IQR 離群值處理在資料切分前完成，評估結果可能略為樂觀；後續可改為只由訓練集計算 IQR 上下界，再套用到測試集。
- EDA 的相關係數只表示關聯，不代表因果。
- 模型使用 89 個特徵（含 `Total_px`），不能單獨推論解析度對價格的因果效果。
- 殘差與預測值的相關係數只是描述性診斷，不是正式的異質變異檢定；分組誤差僅為本次測試集的觀察。
- 資料來自 momo 公開商品頁，僅供學習研究與作品展示，請勿用於商業用途。
